# C++ Learning Journey

## Goals

- Learn C++ fundamentals and tooling
- Master memory management, RAII, and concurrency
- Write safe, performant, idiomatic C++

## Structure

- basics/ – core language fundamentals
- memory/ – ownership, lifetime, RAII
- stl/ – containers and algorithms
- templates/ – generic programming
- concurrency/ – threading and atomics
- performance/ – optimization techniques
- projects/ – real-world applications

## Build

```bash
cmake -S . -B build
cmake --build build
```
